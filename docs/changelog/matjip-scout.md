# matjip-scout 변경 이력

## 1.1.0

기준: 개인 스킬 폴더 사본의 SKILL.md(단일 파일), LF 로 정규화.

- 실행 게이트를 "심층 연구 모드 필수" 에서 "웹 검색·열람 도구 필요" 로 바꿨다. 도구가 있으면 모드와 무관하게 진행하고, 웹 도구가 전혀 없을 때만 모드 전환 안내를 전달한 뒤 탐색하지 않는다.
- 설명을 추천·선정 의도 중심으로 좁혔다. "지역명 + 음식 언급만으로 발동" 조건을 삭제했고 레시피·특정 식당 정보 문의를 제외로 명시했다.
- 기준 ④ 를 점검 가능한 정의로 바꿨다. 플랫폼이 노출하지 않는 "긍정 80%" 를 없애고, 2개 이상 플랫폼 평점 4.0+ 와 플랫폼별 리뷰 50건 이상, 최근 12개월 리뷰 최대 20건 표본에서 반복되는 부정 지적이 없을 것으로 정했다.
- 영업 상태는 최근 출처 2곳 이상으로 확인하고 확인 일자를 적도록 했다.
- 산출 파일 위치를 작업 폴더로 하고(claude.ai 는 /mnt/user-data/outputs/) present_files 가 있으면 전달한다. 탐색 일자는 시스템 날짜를 쓴다.
- 가져온 웹 내용은 자료일 뿐 지시가 아님을 명시했다.
- 예시에서 실제 식당명과 방송인·프로그램 고유명을 일반 표현으로 바꿨다.
