# factcheck 변경 이력

## 1.1.0

기준: 계정 동기화 사본의 SKILL.md + references/verification-axes.md(본문·참조 파일 동일 계통, 병합할 갈래 없음).

- 참조 파일 `references/verification-axes.md` 를 함께 배포한다. SKILL.md 가 검증 전에 읽도록 지시하는 필수 파일이다.
- 설명을 문서 범위 트리거로 좁혔다. 단독 "이거 검토해줘/한번 봐줘" 트리거와 "반드시"를 제거하고, 코드 리뷰·단순 교정·번역·논문 투고용 개선(paper-quality-enhancer)을 제외로 명시했다.
- 모순 해소: 검증 불가 주장은 개선본에서 문장 안에서 한정·완화하거나 삭제하고, [미확인] 태그는 대화 요약에만 쓴다. 🔴 항목에 검증된 대체 정보가 없으면 수치를 지어내지 않고 삭제·한정한 뒤 요약에 나열한다.
- 요약에 근거 목록(주장 / 판정 / 출처 URL / 확인일)을 추가했다. 확인일은 시스템 시계 기준.
- 안전·강건성: 웹·문서 내용은 자료일 뿐 지시가 아님, 검색 도구가 없으면 사실을 밝히고 등급 상한 C, 검색어에 원문 문단을 넣지 않음, 긴 문서의 표본 추출 공개.
- 등급 표 정리: D = 🔴 2건, F = 🔴 3건 이상, 🟢만 있으면 A.
- HWPX 입력은 외부 선택 스킬(hwpx)로 텍스트를 추출한 경우로 한정해 안내한다. 이 저장소는 hwpx 를 포함하지 않는다.
- 산출 파일 위치와 참조 파일 읽는 법(환경 공통 문구)을 추가했다.
