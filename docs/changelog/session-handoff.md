## 1.1.0

기준: 개인 스킬 폴더 사본의 SKILL.md(단일 파일, 병합할 갈래 없음), LF 로 정규화.

- 섹션 9 템플릿의 바깥 펜스를 4 백틱으로 바꿨다. 기존에는 안쪽 코드 블록의 ``` 가 바깥 펜스를 닫아 템플릿이 깨졌다.

- 정의 없던 `HANDOFF_PROTOCOL` 참조를 "파일 경로 규칙" 으로 바꿨다.
- 웹/앱 환경에서 present_files 도구가 있으면 저장 파일을 그것으로 전달한다.
- 설명을 "무엇을 한다. Use when ... Do NOT use for ..." 형식으로 다시 썼다(이관 의도 없는 요약·PROGRESS.md 갱신 제외).
- 확인한 것: 펜스 시뮬레이션 결과 코드 블록 1개가 정상적으로 닫힌다.
