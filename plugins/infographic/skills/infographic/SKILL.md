# 문서 인포그래픽 자동 생성 스킬

어떤 문서든 핵심 내용을 도식화한 고품질 인포그래픽 HTML 페이지를 생성한다.
정부·공공 지원사업 제출 문서(사업계획서·연구개발계획서)는 개요 셀 산출물까지 만드는 gov-doc-infographic 이 맡는다.

## 사용 전 필수 행동

이 스킬이 트리거되면, 먼저 이 SKILL.md 와 같은 폴더의 `references/design-rules.md` 를 읽어라.
스킬의 참조 파일은 이 SKILL.md 가 있는 폴더 기준 상대 경로로 읽는다.

## 핵심 원칙

1. **수치 정확성**: 원문 수치 그대로. 반올림·추정·창작 금지.
2. **잘림 금지**: max-height+overflow:hidden 금지. height:auto.
3. **순서 유지**: 원문 목차 순서 = 인포그래픽 순서. 뒤섞기 금지.
4. **개인정보 마스킹**: 이름→성OO, 학교→OO대.
5. **배경 = 흰색**: #FFFFFF 또는 transparent만. 유색 배경 블록 0개. 인쇄 시 배경 잉크 0.
6. **텍스트 = 검정**: #000000. 출처와 캡처 라벨(.cap-label, 인쇄 시 숨김)만 #666666 허용. 회색·컬러 텍스트 금지.
7. **테마컬러 1개만**: 문서 주제에 어울리는 뮤트 톤 1색. 보라색 계열 금지.
8. **Pretendard 단일**(오프라인 폴백 스택 제외): 본문 최소 16px. 14px 미만(출처·캡처 라벨 외) 금지.
9. **이모지 완전 금지**: HTML 어디에도 이모지 문자 0개. 캡처 라벨도 텍스트만.
10. **AI스러운 디자인 금지**: 둥근 파스텔 카드, 알록달록, 그라데이션 배경, 이모지 아이콘 등 전형적 AI 패턴 절대 금지.

## 워크플로우

### STEP 1: 문서 읽기 + 분석

**파일 확보** → 파일 접근이 가능한 에이전트 환경: 경로 탐색. 채팅: 첨부 파일.

**문서 유형 판단** → 사업계획서/연구개발/제안서/보고서/기획서/기타. 정부지원사업 제출 문서면 gov-doc-infographic 을 쓰도록 안내한다.

**테마컬러 선택** → 문서 산업·주제에 어울리는 뮤트 톤 1색 선택. design-rules.md의 컬러 가이드 참조. 보라색 금지.

**목차 파악** → 실제 목차 순서번호 기록. 다른 양식 가정 금지.

**도식화 대상 선별** → design-rules.md 기준.

**데이터 추출 + 마스킹** → 정량·구조 데이터 + 성OO/OO대.

### STEP 2: 섹션 설계
15~20개, 원문 순서, 패턴 다양화, 콘텐츠 많으면 분할.
원문이 짧아 의미 있는 섹션이 15개에 못 미치면 억지로 채우지 않고, 만든 섹션 수와 이유를 밝힌다.

### STEP 3: HTML 생성
design-rules.md 전 규칙 적용.

### STEP 4: 검증
design-rules.md 체크리스트 전항을 확인하되, 읽어서 판단하지 말고 가능한 방법으로 실측한다.
1. 헤드리스 브라우저(Playwright, Chrome/Edge `--headless`)가 있으면 900px 폭으로 렌더해 잘림·가로 스크롤·겹침이 없는지 본다.
2. 브라우저가 없으면 생성한 HTML 을 텍스트로 검사한다: 이모지 문자, 보라색 계열 hex, 본문 font-size 16px 미만, `max-height`/`overflow:hidden`, #000·#666 외 텍스트 색.
3. 두 경우 모두 HTML 의 숫자 문자열을 원문과 대조한다(원문에 없는 수치 0건).
산출 보고에 1·2 중 무엇을 실행했는지, 실행하지 못한 검사가 무엇인지 밝힌다.

### STEP 5: 출력
산출 파일은 작업 폴더에 저장한다(claude.ai 에서는 /mnt/user-data/outputs/). 파일명은 `infographics.html`. present_files 도구가 있으면 그것으로 전달한다. 스킬의 참조 파일은 이 SKILL.md 가 있는 폴더 기준 상대 경로로 읽는다.
파일을 쓸 수 없는 채팅 환경: HTML 코드블록.

## 실패 모드

- **스캔 PDF·이미지뿐인 원문**: 텍스트를 읽을 수 없으면 추정하지 말고 텍스트 파일이나 OCR 결과를 요청한다.
- **정량 데이터가 없는 원문**: 구조도·프로세스·비교표로 도식화한다. 수치를 만들어 채우지 않는다.
- **오프라인**: Pretendard CDN 을 못 불러오면 design-rules.md 의 폴백 스택으로 렌더되므로 글꼴이 다를 수 있다고 밝힌다.
