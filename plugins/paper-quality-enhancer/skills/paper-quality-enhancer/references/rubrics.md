# PQE 루브릭

SKILL.md 가 실행 중 참조하는 단일 기준 파일이다. 해당 절만 읽고 적용한다. 기준은 일반적 학술 관행이며, 특정 저널의 현행 투고 규정은 저자가 확인한다.

## 1. 논문 유형 9분류 (SCOPE_ANALYST)

이론·개념 / 실증·정량 / 실증·정성 / 혼합방법 / 방법론·기법 / 리뷰·메타분석 / 사례연구 / 포지션·의견 / 응용·재현. 유형이 평가 기준을 바꾼다: 이론 논문에 검정력·표본 기준을 요구하지 않고, 포지션 논문에 효과크기를 요구하지 않는다.

## 2. 8축 테스트 (통과 기준 / 대표 결함)

| 축 | 통과 기준 | 대표 결함 |
|---|---|---|
| 1 논증 | 문제 → 주장 → 근거 → 결론이 끊김 없이 이어지고 결론이 근거 범위를 넘지 않는다. 대안 설명을 다룬다 | 비약, 순환논증, 상관을 인과로 서술, 초록 주장이 본문에 없음 |
| 2 문헌 | 핵심 선행연구와 최근 5년 흐름, 상충 견해를 다루고 공백이 명시된다 | 자기 인용 편중, 핵심 논쟁 누락, 문헌 나열만 있고 종합이 없음 |
| 3 방법론 | 유형·분야에 맞는 설계, 표본·측정·분석 정당화, 한계 명시 | 표본 근거 없음, 분석 선택 사후 정당화, 기준선 부재 |
| 4 인용 | 모든 인용이 실존하고 서지(저자·연도·출처)와 주장 내용이 일치한다 | 존재하지 않는 문헌, 연도·저자 오류, 인용이 주장을 뒷받침하지 않음 |
| 5 기여 | 기여가 1-3문장으로 말해지고 기존 연구 대비 차이가 구체적이다 | "최초" 남용, 기여와 결과의 불일치, 증분이 불분명 |
| 6 명료성 | 초록·서론이 독립적으로 읽히고 용어가 일관되며 그림·표가 본문과 맞는다 | 용어 혼용, 약어 미정의, 문단당 주제 2개 이상 |
| 7 재현성 | 데이터·코드·절차·환경이 공개되거나 공개 불가 사유가 적혀 있다 | 하이퍼파라미터·전처리·제외 기준 누락, 접근 불가 링크 |
| 8 윤리 | 승인·동의·이해충돌·자금·저자 기여·AI 도구 사용이 공개된다 | IRB/동의 언급 없음, 이해충돌 미기재, 중복 게재 의심 |

## 3. 분야별 엄밀성

| 분야 | 우선 확인 | 주의 |
|---|---|---|
| STEM | 불확실성·오차, 대조군·교정, 단위·유효숫자, 재현 가능한 프로토콜 | 이론 논문은 유도 완결성과 가정 명시 |
| 사회과학 | 식별 전략, 측정 타당도·신뢰도, 표본 대표성, 사전 등록·다중 검정 | 정성 연구는 신뢰성(삼각검증, 성찰성)으로 평가 |
| 인문학 | 1차 자료 해석의 정확성, 이론 틀 대화, 논증의 독창성 | 재현성·효과크기 기준을 적용하지 않는다 |
| 의학 | 연구 설계 등급, 보고 지침(CONSORT·STROBE·PRISMA 등 해당 유형), 윤리 승인, 임상적 의의 | 통계적 유의성과 임상적 유의성 구분 |
| AI·CS | 강한 기준선, 절제 실험, 다중 시드 분산, 데이터 누수·평가 오염, 코드·모델 공개 | 벤치마크 외 일반화 주장 자제 |
| 경제·경영 | 식별과 내생성 처리, 강건성 검증, 이론-실증 연결, 경제적 크기 해석 | 관측 연구의 인과 표현 |

분야가 교차하면 주 분야 기준을 적용하고 인접 분야는 보조로 쓴다.

## 4. 투고 티어

| 티어 | 기대 수준 | 개선 임계값 |
|---|---|---|
| 1 분야 최상위 | 분야 지형을 바꾸는 기여, 완결된 검증, 강한 기준선 | 모든 축 상, 기여·방법론 결함은 P0 |
| 2 분야 상위 | 명확한 증분과 견고한 검증 | 기여·방법론 P1, 문체는 P2 |
| 3 분야 표준 | 정확하고 투명한 보고, 타당한 결론 | 인용·윤리·재현성 중심, 과도한 요구 금지 |

티어는 저자 지정 우선, 없으면 추정하고 근거를 리포트에 적는다. 간극은 Small(표면 다듬기) / Medium(구조 보강) / Large(핵심 재작업, 저자와 논의)로 판정한다.

## 5. Reviewer 2 패턴

공통: "새로움이 무엇인가", "왜 이 방법인가", "일반화되는가", "대안 설명을 배제했는가", "한계가 과소 서술됐다".

| 분야 | 자주 나오는 비판 |
|---|---|
| STEM | 대조 실험 부족, 오차 분석 없음, 조건 범위 밖 외삽 |
| 사회과학 | 내생성, 측정 타당도, 표본 편향, 효과 크기 해석 |
| 인문학 | 선행 해석과의 차별성 불분명, 자료 선택 편향, 이론 적용의 기계성 |
| 의학 | 선택·교란 편향, 표본 부족, 임상적 의의 불명, 보고 지침 미준수 |
| AI·CS | 약한 기준선, 절제 실험 부재, 평가 오염, 계산 비용 미보고 |
| 경제·경영 | 식별 전략 취약, 강건성 부족, 외적 타당성 |

REVIEWER_SIMULATOR 절차: 위 패턴에서 5-10개 비판을 만들고 각각 "방어 가능 / 부분 가능 / 불가"로 판정하며, 불가·부분에는 대응 전략(원고 수정, 추가 분석, 한계 명시)을 쓴다. 친절한 제안자가 아니라 거절 사유를 찾는 관점으로 쓴다.

## 6. 개정 카드 (4단)

모든 제안은 4개 필드를 채운다.

```
[ID | 우선순위 P0-P3 | 축]
원문 위치: 섹션·단락·문장 (원문 인용 1문장)
문제 진단: 무엇이 왜 문제인가
해결안: 저자가 그대로 적용할 수 있는 수정 문장·구조
근거: 학술 관행·표준·검증된 선행연구 (검증 못 한 문헌은 "저자 확인 필요")
```

우선순위: P0 투고 거절 리스크(환각 인용, 명백한 논리 결함, 필수 문헌 누락, 윤리 위반 의심) / P1 심사 통과 필수 보강 / P2 경쟁력 제고 / P3 선택적 강화. P0·P1은 본문에 반영하고, P2는 저자 판단이 필요한 것만 리포트에 남기며, P3는 리포트에만 적는다.

축별 진단 카드는 축 이름, 판정(상·중·하), 근거 위치 목록, 개정 카드 ID 목록으로 구성한다.

## 7. 심사 리포트 골격 (8개 섹션)

1. 요약 판정: 분야·유형, 현재 수준, 목표 티어, 간극, 투고 추천 티어
2. 8축 진단: 축별 판정과 핵심 근거
3. 핵심 개선사항 Top 3
4. 개정 카드 전체 (P0 → P3, 반영 여부 표시)
5. Reviewer 2 시뮬레이션: 비판, 방어 판정, 대응 전략
6. Desk-reject 리스크: 범위 적합성, 형식 요건, 윤리·중복 게재, 초록 명료성
7. 인용 검증 결과: 기존 인용 검증 표와 새로 추가한 인용의 검증 근거
8. 저자 확인 필요 항목: 확인 못 한 수치·인용·고유명, 추가 정보 요청(투고 목표, 제약조건, 이전 심사 코멘트)

## 8. 환각 방지·Chain-of-Verification

1. 새 인용은 검색 도구로 실존을 확인한다(저자·연도·제목·출처가 서로 일치). 확인 못 하면 추가하지 않는다.
2. 기존 인용은 CITATION_VERIFIER 가 하나씩 검증하고 결과를 확인됨 / 불일치 / 확인 불가로 표시한다.
3. 수치·연도·저자·기관명·학회명은 확신이 없으면 "저자 확인 필요"로 표시한다. 기억으로 채우지 않는다.
4. CoV: 새로 도입한 항목마다 독립 검증 질문(이 문헌은 실제로 있는가, 이 수치의 출처는 무엇인가)을 만들어 별도로 재검색한다. 불일치면 고치거나 제거한다. 지점 A(원고 기존 인용)와 지점 B(새 인용) 두 번 통과해야 산출물에 남는다.
5. 검색 도구가 없으면 그 사실을 리포트 첫머리에 밝히고, 새 인용은 추가하지 않으며, 기존 인용은 모두 "확인 불가"로 둔다.
6. 검색어에는 일반적 주장·서지 정보만 넣는다. 미공개 원고의 문단을 통째로 넣지 않는다.

## 9. 점검 목록

PHASE 1 중간 점검(4개 축 완료 시): 진단 카드가 판정과 위치 근거를 갖췄는가 / 축 간 권고가 충돌하지 않는가 / 분야 기준이 올바르게 적용됐는가 / 인용 검증 결과가 다른 축에 반영됐는가.

Desk-reject 점검: 저널 범위 적합성, 분량·형식, 초록이 기여를 말하는가, 윤리 승인·이해충돌 기재, 중복 게재·표절 의심, 필수 보고 지침 준수.

최종 QA: 개선본과 리포트가 모두 있다 / 저자 논지가 보존됐다(초록 비교) / 새 인용이 전부 검증됐다 / P0 가 본문에 반영됐다 / 모든 제안이 4단 구조다 / 분야 오적용이 없다 / 개선본 언어가 원고와 같다 / 저자 확인 필요 항목이 리포트 8번에 있다. 하나라도 실패하면 해당 단계로 돌아간다.
