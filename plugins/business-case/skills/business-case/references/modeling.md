# 모델링 규칙 — TAM/SAM/SOM · CAC · LTV · 성장곡선

모델링 단계 시작 전에 읽어라. 여기 적힌 오류들은 실제 사업계획서에서 반복적으로 나온다.

---

## 1. TAM / SAM / SOM

### 정의를 혼동하지 마라

| 층 | 뜻 | 흔한 오용 |
| -- | -- | -- |
| **TAM** | 이 문제를 가진 모두가 매년 쓰는 돈 | 인접 산업 전체를 끌어와 부풀림 |
| **SAM** | 그중 **우리 제품 형태로** 도달 가능한 부분 | TAM 과 거의 같게 잡아 무의미해짐 |
| **SOM** | 우리가 3년 안에 **실제로** 얻을 부분 | TAM×1% 라는 마법의 숫자 |

### 반드시 두 방법으로 계산하고 차이를 설명하라

**하향식**: 시장규모 통계 → 세그먼트 필터 → 도달 가능 비율
**상향식**: 연간 발생하는 구매 트리거 수 × 우리 제품이 붙을 수 있는 비율 × 객단가

두 값이 3배 이상 벌어지면 **둘 중 하나의 가정이 틀렸다는 신호**다. 평균내지 말고
어느 쪽이 왜 틀렸는지 찾아라. 보통 하향식이 부풀려져 있다.

### SOM 은 획득 경로에서 역산하라

`SOM = 3년간 획득 가능한 고객 수 × 객단가` 이고, 획득 가능한 고객 수는
**예산 ÷ CAC** 와 **유기적 유입의 현실적 상한** 중 작은 쪽이다.

시장 점유율 %에서 출발하면 반드시 부풀려진다. "1%만 먹어도"는 분석이 아니라 소원이다.
**첫 100명, 첫 1,000명을 어떻게 얻는지 문장으로 쓸 수 없다면 SOM 숫자는 허구다.**

## 2. 단위 경제 (Unit Economics)

매출 1건에서 차감할 것을 빠뜨리지 마라:

```
판매가
  − 세금(부가세 등)                    ← 판매가가 세포함인지 반드시 확인
  = 순매출
  − 결제 수수료 (정률 + 정액)          ← 정액이 있으면 소액에서 치명적
  − 변동 원가 (API·원재료·외주)        ← 최악 시나리오로 잡아라
  − 인프라 (컴퓨트·스토리지·대역폭)
  − 건당 지원·환불 기대비용            ← 환불률 × 판매가
  = 기여이익 (Contribution Margin)
```

**기여이익이 곧 손익분기 CAC 다.** CAC 가 기여이익을 넘으면 팔수록 손해다.

### 원가만 보고 안심하지 마라

마진율 90%는 좋은 신호가 아니라 **중립 신호**다. 대부분의 소비자 사업은 원가가 아니라
획득 비용으로 죽는다. 마진율을 낸 다음 **반드시** 손익분기 CAC 와 필요 CPC 를 내라.

## 3. CAC

### 유료 CAC 와 블렌디드 CAC 를 분리하라

```
유료 CAC     = 광고비 ÷ 광고로 획득한 고객 수
블렌디드 CAC = 전체 마케팅비 ÷ 전체 신규 고객 수 (유기적 포함)
```

블렌디드만 제시하는 계획서는 대개 유기적 유입으로 유료 CAC 의 실패를 가리고 있다.
**둘 다 내라.** 그리고 성장하려면 유료 채널이 성립해야 한다는 점을 명시하라.

### 퍼널을 단계별 %로 드러내라

```
노출 → 클릭(CTR) → 랜딩 도달 → 핵심행동 → 결제(CVR)
```

각 단계 전환율에 출처나 근거를 붙여라. 곱해보면 대개 낙관적으로 잡혀 있다는 게 드러난다.

### 필요 CPC 역산 — 가장 빠른 판정 도구

```
감당 가능한 최대 CPC = 기여이익 × 방문→결제 전환율
```

이 값을 해당 카테고리의 **실측 CPC** 와 나란히 놓아라. 실측 CPC 가 크게 높으면
유료 검색은 구조적으로 불가능하고, 사업 성립 여부는 무료 채널·업셀·제휴로만 결정된다.
이 결론을 흐리지 마라.

## 4. LTV — 구조적 상한을 정면으로

### 공식보다 먼저 확인할 것

LTV 공식을 쓰기 전에 **재구매가 물리적으로 가능한가**를 답하라:

| 확인 | 함의 |
| -- | -- |
| 계정·로그인이 있는가 | 없으면 재방문 유도 채널(이메일·푸시)이 구조적으로 없다 |
| 고객 식별자를 보관하는가 | 없으면 재구매를 측정조차 못 한다 |
| 데이터 보관기간 | 짧으면 재방문 유인이 사라진다 |
| **구매 주기** | 수년 주기 카테고리면 LTV ≈ 1회 구매 |
| 상위 티어가 실재하는가 | "예정"은 LTV 에 넣지 마라 |

이 중 하나라도 막혀 있으면 **LTV 는 리스크가 아니라 상한(ceiling)이다.** 리스크 목록에
묻어두지 말고 별도 절에서 정면으로 다뤄라. 대부분의 사업계획서가 여기서 자기를 속인다.

### 계산

```
LTV = 기여이익 × (1 + 기대 재구매 횟수) + Σ(업셀 티어 기여이익 × 업셀 전환율)
```

재구매 횟수와 업셀 전환율은 **반드시 실측 벤치마크에서** 가져와라. 근거 없는 가정이면
`[가정]` 을 붙이고 감도분석을 함께 제시하라 — 이 두 값에 LTV 가 가장 민감하다.

할인율을 쓴다면 명시하라. 1회성 구매에 가까우면 할인은 거의 무의미하다.

### 판정

| LTV/CAC | 해석 |
| -- | -- |
| < 1 | 팔수록 손해. 사업이 아니다 |
| 1 ~ 3 | 생존은 하나 성장 자금을 못 만든다 |
| ≥ 3 | 통상적 건강 기준 |

회수기간(payback)도 함께 낸다. 1회성 결제면 회수는 즉시이거나 영영 안 된다 — 중간이 없다.

---

### 4-b. 구독·B2B 변형 (재구매가 아니라 이탈률로 LTV 를 잡는다)

반복 과금 사업은 "재구매 횟수" 대신 **이탈률**이 LTV 를 결정한다. 식 4개와 약속 3개를 쓴다.

```
월 기여이익(ARPA×마진) = 월 평균 과금액(ARPA) × 매출총이익률
기대 수명(개월)        = 1 ÷ 월 이탈률 (고객 수 기준 logo churn)
LTV                    = 월 기여이익 × 기대 수명
CAC 회수기간(개월)     = CAC ÷ 월 기여이익
NRR                    = (기초 MRR + 확장 − 축소 − 이탈) ÷ 기초 MRR
```

- 월 이탈률은 연 이탈률로 바꿔 읽어라: 연 이탈률 = 1 − (1 − 월 이탈률)^12. 월 4% 는 연 약 38.7% 다.
- 기대 수명은 **상한을 둔다**(소비자 구독은 통상 36개월, B2B 는 5년 등 근거를 적은 값). 이탈률이 낮을수록 1÷이탈률이 비현실적으로 커지므로 상한 없는 LTV 는 `[가정]` 으로만 쓴다.
- CAC 는 영업 인건비를 포함한 **완전 부담 비용**(영업+마케팅 총액 ÷ 신규 고객 수)으로 잡는다. 인건비를 빼면 B2B 의 CAC 는 절반 이하로 보인다.
- NRR ≥ 100% 면 기존 고객 확장이 이탈을 덮는다는 뜻이지만, 고객 수 이탈률과 따로 보고 둘 다 낸다.
- 회수기간은 12개월 이하가 건강, 18개월을 넘으면 자금 압박 신호로 읽는다 (통상 기준이며 시장·단가에 맞게 `[가정]` 으로 조정).

**작업 예시 1 — 소비자·SMB 구독** (숫자는 가상, 금액은 부가세 제외)

| 항목 | 값 | 계산 |
| -- | --: | -- |
| ARPA | 50,000원/월 | 입력 |
| 매출총이익률 | 80% | 입력 |
| 월 기여이익 | 40,000원 | 50,000 × 0.80 |
| 월 이탈률 | 4% | 입력 |
| 기대 수명 | 25개월 | 1 ÷ 0.04 |
| LTV | 1,000,000원 | 40,000 × 25 |
| CAC | 400,000원 | 입력 |
| LTV/CAC | 2.5 | 1,000,000 ÷ 400,000 → "1~3 구간: 생존은 하나 성장 자금 부족" |
| 회수기간 | 10개월 | 400,000 ÷ 40,000 |
| 연 이탈률 | 약 38.7% | 1 − 0.96^12 |

**작업 예시 2 — B2B 연 계약** (상한 효과를 보이기 위한 예시)

| 항목 | 값 | 계산 |
| -- | --: | -- |
| ACV | 12,000,000원/년 | 입력 |
| 매출총이익률 | 70% | 입력 |
| 연 기여이익 | 8,400,000원 | 12,000,000 × 0.70 |
| 연 이탈률 | 10% | 입력 |
| 기대 수명 | 5년 | 1 ÷ 0.10 = 10년이나 상한 5년 적용 |
| LTV | 42,000,000원 | 8,400,000 × 5 (상한 없으면 84,000,000원) |
| CAC | 20,000,000원 | (영업+마케팅 300,000,000원) ÷ 신규 15곳 |
| LTV/CAC | 2.1 | 42,000,000 ÷ 20,000,000 (상한 없으면 4.2 — 결론이 뒤집힌다) |
| 회수기간 | 약 28.6개월 | 20,000,000 ÷ 8,400,000 × 12 |
| NRR 예 | 100% | 기초 MRR 100 + 확장 8 − 축소 2 − 이탈 6 = 100 (단위 백만원) |

두 번째 예시가 보여주듯 **수명 상한을 어디에 두느냐가 LTV/CAC 를 2배로 바꾼다.** 상한의 근거를 보고서에 적고, 감도분석(수명 3·5·7년)에 반드시 넣어라.

## 5. 성장곡선

12분기(3년) 표로 낸다. 각 분기에 최소한:

`유료 주문수 · 매출 · 마케팅비 · 기여이익 · 누적 현금`

지켜야 할 것:
- **계절성을 반영하라.** 대부분의 카테고리에 월별 편차가 있다
- 초기 분기에 유기적 유입을 과대하게 넣지 마라 — 이게 가장 흔한 조작이다
- 손익분기 시점을 명시하라. 3년 안에 안 오면 그렇게 쓴다
- 누적 현금의 최저점(=필요 자금)을 밝혀라. 이게 실질적으로 가장 중요한 숫자다
- 곡선이 J커브면 J커브의 **바닥 깊이와 기간**을 숫자로

## 6. 흔한 수치 오염 7종 (검증자에게 반드시 전달)

1. **GMV를 매출로 표기** — 플랫폼 거래액과 수수료 매출은 10배 이상 차이 난다
2. **상위 시장을 하위 시장으로** — "건설 시장"을 "인테리어 시장"으로 부르는 식
3. **단위 혼동** — 억/조, million/billion. 한국어 자료에서 특히 잦다
4. **연도 혼동** — 5년 전 수치를 현재로 인용
5. **해외 수치를 국내에 적용** — CPC·전환율·수수료율은 시장마다 배수로 다르다
6. **전망치를 실적으로** — "2030년 X조 전망"을 현재 시장 규모로 인용
7. **출처 세탁** — 언론이 인용한 업계 추정치가 반복 인용되며 사실처럼 굳는 현상.
   원 출처까지 거슬러 올라가면 근거가 없는 경우가 흔하다

## 7. 감도분석

결론을 뒤집는 변수 2~3개를 골라 범위를 흔들어 보여라. 보통 이 셋이다:

- **CAC** (가장 자주 결론을 뒤집는다)
- **전환율**
- **업셀/재구매율**

각 변수를 낙관·기준·비관으로 놓고 LTV/CAC 가 3을 넘는 구간이 존재하는지 보여라.
**어떤 조합에서도 3을 못 넘으면 그게 결론이다.** 돌려 말하지 마라.
